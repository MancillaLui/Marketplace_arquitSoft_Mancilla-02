# Actores del Sistema

| Actor | Tipo | ¿Qué necesita realizar? |
| :--- | :--- | :--- |
| **Cliente** | Humano | Buscar productos, consultar información, agregar productos al carrito, realizar pedidos, efectuar el pago y consultar sus pedidos. |
| **Seller** | Humano | Ofrecer productos, registrar productos, actualizar productos, consultar sus productos y gestionar la información relacionada con sus ventas. |
| **Administrador** | Humano | Administrar la plataforma y gestionar los vendedores registrados. |
| **Pasarela de pago** | Sistema Externo | Procesar las transacciones y pagos del cliente. |
| **Servicio de envío** | Sistema Externo | Gestionar la información de entrega y logística de pedidos. |
| **Servicio de Facturación** | Sistema Externo | Generar los comprobantes de pago. |
| **ERP** | Sistema Externo | Proporcionar la información de catálogo y stock. |
